# corvus-web-studio

Portfolio of Corvus Web Studio (Dylan Tuna): games, services, news, career.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm run start
npm run lint
npm run typecheck
```

Set `NEXT_PUBLIC_SITE_URL` to the production origin (canonical URLs, sitemap,
Open Graph). See [ARCHITECTURE.md](./ARCHITECTURE.md) for the folder layout
and conventions.
